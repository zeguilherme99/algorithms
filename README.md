# Reverse

## Problema "reverse"

### Descrição do Problema:
Faça uma função que receba uma lista (de qualquer tipo) e retorne a lista reversa.
### Exemplos:
#### Exemplo 1:
**Entrada:**  
`[]`

**Saída:**  
`[]`

#### Exemplo 2:
**Entrada:**  
`["azul"]`

**Saída:**  
`["azul"]`

#### Exemplo 3:
**Entrada:**  
`["azul", "verde", "preto", "rosa"]`

**Saída:**  
`["rosa", "preto, "verde", "azul"]`
