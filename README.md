# Soma naturais

## Problema "soma-naturais"

### Descrição do Problema:
Faça uma função que, dado um número natural N, retorne a soma dos números de 0 até N.

### Exemplos:
#### Exemplo 1:
**Entrada:**  
`0`

**Saída:**  
`0`

#### Exemplo 2:
**Entrada:**  
`2`

**Saída:**  
`3`

#### Exemplo 3:
**Entrada:**  
`4`

**Saída:**  
`10`
